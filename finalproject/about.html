About Movie Explorer

Project Overview

Movie Explorer is a student web development project that dynamically displays movie data using JSON, JavaScript modules, and responsive design principles.

Features

✔ Dynamic movie rendering using JSON

✔ Modal popups for movie details

✔ Local storage for user interaction tracking

✔ Responsive layout for all devices

Technologies Used

HTML5, CSS3, JavaScript (ES Modules), JSON
